# История изменений

Все записи ведутся на русском языке. Версия приложения и версия расширения Chrome выпускаются независимо.

## [1.0.3] — 2026-10-15

### Добавлено

- Сохраняемая папка загрузок по умолчанию: системная папка «Загрузки» с подпапкой `Mangar`, кнопки «Изменить» и «Сбросить» в настройках.
- Временный выбор папки на главном экране независимо от default; после нового запуска используется сохранённая настройка.
- Настройка «Спрашивать папку при загрузке из расширения». По умолчанию выключена; задания используют default без обязательного выбора папки. Недоступная папка не приводит к незаметной смене места сохранения.
- Диагностический журнал очистки устаревших версий управляемых компонентов.

### Исправлено

- Запуск Mangar через «Открыть Mangar Downloader» после установки: приложение открывается после завершения установщика.
- Сохранение настроек при обновлении, совместимость старых settings и обработка запросов браузера при запуске приложения.
- Усилена защита текущих, предыдущих и используемых версий компонентов при очистке: повторная проверка перед удалением, сохранение при ошибках чтения manifest и межпроцессные leases.

### Изменено

- Подтверждена интеграция с опубликованным расширением Chrome Web Store: передача страницы, загрузка обнаруженного MP4 и автоматический запуск Mangar.
- Пользовательские инструкции обновлены для обычных стабильных выпусков и новой настройки папки.
- Сохранены три одновременные загрузки, fragment concurrency `-N 8`, лучший доступный video/audio, итоговый MP4 и защита существующих файлов от перезаписи.

Расширение Chrome Web Store остаётся на версии **1.0.1**. Новые popup и иконки будут опубликованы отдельно.

## Предыдущие тестовые выпуски

- **1.0.2 RC1** — установка для текущего пользователя, production Native Messaging для Store-расширения. Ошибка запуска на последней странице установщика исправлена в 1.0.3.
- **1.0.0 RC1** — подготовка приложения для совместной работы с Chrome Web Store; управление компонентами, трей и публичный updater.
- **0.9.2** — публичный тест обновления с сохранением настроек, компонентов и готовых MP4.

### Ранее реализовано

- Загрузка ссылок и TXT, RAM-очередь, отмена, повторная попытка и имена `N.mp4` для TXT.
- Необязательное расширение Chrome/Edge: отдельная передача текущей страницы и обнаруженного медиапотока с ограниченным контекстом запроса.
- Настройка cookies браузера, закрытие в трей, светлая/тёмная/системная тема и компактный интерфейс.
- Безопасные имена файлов, отсутствие перезаписи, краткие русские сообщения ошибок и открытие готового файла или папки.
- Управляемые yt-dlp, FFmpeg/ffprobe и Deno; проверка обновлений приложения через публичные GitHub Releases без токенов.
