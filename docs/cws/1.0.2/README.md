# Store screenshots — расширение 1.0.2

Финальные PNG пересняты 15 октября 2026 года после визуального принятия владельцем popup из commit `e02b637cc34c6e8e11651b2bcc7b0b792a41c8e8`. Они заменяют прежние изображения с большой privacy-секцией и footer.

Три PNG, 640×400, RGB без alpha: поддерживаемая страница YouTube, обнаруженный MP4 на публичной W3Schools HTML5 video page и та же media-карточка с раскрытой privacy-панелью. Это настоящие снимки Chrome с action popup отдельного чистого профиля, без mockup, DevTools, персональных данных и служебных баннеров. Захвачена область окна браузера 640×400 при масштабе 1×, без изменения размера и дорисовки. Popup сохраняет естественную высоту 111/132/218 px; header неподвижен, ⓘ справа, panel в потоке, radius 4 px, весь текст виден без внутреннего scrollbar.

Runtime-файлы распакованы из финального production ZIP 1.0.2, собранного из указанного clean commit: 36 060 байт, SHA-256 `74847856d7cfe12af79a632c8b515b6ad9715f68179ed8f38e7f63553a2a3aa1`. Для связи тестового Chrome с установленным host только в отдельную unpacked копию manifest добавлен repository dev public key; все остальные файлы побайтово совпадают с ZIP. Сам ZIP не содержит key. Точная unpacked-копия ZIP отдельно проверена в Chrome; её временный ID ожидаемо отклоняется Native Messaging host. Production ID `paimennadokhgjdpgilfcebameolopbm` назначается существующим CWS item. Эти проверки не заменяют acceptance обновления, установленного из Store после публикации.

`node scripts/cws-store-assets.mjs` проверяет размеры и экспортирует эти PNG вместе с актуальной packaged icon 128×128 в `dist/release/1.0.2/store/`. На рабочем столе файлы называются `01-page.png`, `02-media.png`, `03-privacy.png`. Чистая папка `Mangar Downloader - Chrome Web Store 1.0.2` содержит только ZIP, эти три PNG и `ИНСТРУКЦИЯ.txt`; отдельная замена Store icon не требуется. Временные captures и test profiles в Git не входят.

Требования CWS проверены 15 октября 2026 года: [официальные правила изображений](https://developer.chrome.com/docs/webstore/images). Допускается от одного до пяти screenshots, PNG/JPEG, 640×400 либо 1280×800. Старые screenshots с прежним popup нужно заменить всеми тремя файлами из этой папки; существующие promo tiles не требуют замены, если не содержат старого интерфейса.
