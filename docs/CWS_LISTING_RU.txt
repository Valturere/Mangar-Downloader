2. ОПИСАНИЕ ПРОДУКТА
Название: Mangar Downloader
Короткое описание (из manifest): Передача текущей страницы или медиапотока в локальный Mangar Downloader для скачивания
Категория: Productivity / Производительность (в актуальном списке может называться «Рабочие процессы»).
Язык: русский.
Подробное описание — вставьте следующий текст:

Mangar Downloader связывает Chrome с локальным Windows-приложением Mangar Downloader. Откройте расширение и нажмите «Скачать в Mangar», чтобы передать текущую страницу для скачивания. Для iframe/HLS/DASH и прямых MP4/WebM можно отдельно выбрать обнаруженный медиапоток. Требуется установленное приложение Mangar Downloader с Native Messaging host.

Передача выполняется только по вашему нажатию. Для выбранного медиапотока приложение может получить адрес, разрешённые заголовки и cookies конкретного запроса. Контекст используется для выбранного скачивания и передаётся локально приложению; серверу разработчика данные не отправляются. Найденные потоки хранятся временно и очищаются по истечении срока, навигации и закрытии вкладки. DRM не поддерживается; доступность зависит от источника и сети.

Расширение и companion приложение являются публичным продуктом. Установка и последующие обновления расширения выполняются через Chrome Web Store.

3. КОНФИДЕНЦИАЛЬНОСТЬ
Privacy policy URL: https://valturere.github.io/Mangar-Privacy/
Single purpose — вставьте:
По явному действию пользователя передать текущую страницу или обнаруженный медиапоток в локальное приложение Mangar Downloader для скачивания.

Data categories — отметьте:
Web history / История посещений: адреса страниц и медиазапросов.
Authentication information / Данные аутентификации: cookies и контекст выбранного медиазапроса.
Website content / Содержимое сайтов: названия страниц и доступные metadata медиа.
Если названия переведены иначе, сверяйте смысл. Не выбирайте «данные не обрабатываются»: локальная обработка и передача в приложение есть.
Remote code / Удалённый код: нет.
Данные не продаются; не используются для целей вне single purpose; не используются для оценки кредитоспособности/кредитования. Прочитайте заявления и подтвердите соответствующие certifications / Limited Use согласно этой policy.

Permission justifications — вставьте в соответствующие поля:
webRequest:
Пассивно распознавать HTTP(S)-медиазапросы, MIME, доступные заголовки ответов и связи перенаправлений для iframe/CDN/HLS/DASH. Расширение не блокирует и не изменяет запросы.
cookies:
Получить cookies конкретного наблюдённого медиазапроса с учётом domain/path/secure/partition scope. Они передаются локальному приложению только после выбора потока пользователем. Весь cookie store не экспортируется.
storage:
Хранить только ограниченные временные captures в chrome.storage.session со сроком 15 минут. Постоянное local/sync хранилище не используется.
tabs:
Получить свежие URL и название активной вкладки, показать потоки текущей вкладки и очистить их после закрытия. activeTab недостаточен для фонового наблюдения медиазапросов разных вкладок.
webNavigation:
Очищать контекст при навигации основной страницы и iframe; предотвращать использование устаревших captures после смены страницы.
alarms:
Периодически удалять истёкшие session captures с учётом жизненного цикла MV3 service worker.
nativeMessaging:
По явному нажатию передавать выбранную страницу или медиапоток локальному Native Messaging host ru.mangar.browser.
Host permissions — http://*/* и https://*/*:
Пользователь может выбрать любой HTTP(S) источник, включая cross-origin iframe/CDN. Ограничение одним доменом нарушит основную функцию. Доступ к file:// и служебным схемам браузера не запрашивается; content scripts и удалённый код не используются.
