# Иконка Mangar Downloader

`source-icon.png` — неизменённая project copy предоставленного `user-provided icon`, SHA-256 `45376f12307525da0b463092ad1ec027e38f4e42a6db1988f2ebdfcb3afb7b2c`.

`../appicon.png` — проверенный мастер с слегка скруглёнными внешними углами и прозрачностью снаружи. Редактирование выполнено встроенным imagegen по project copy: сохранить композицию M + стрелка, цвета и минималистичный стиль; изменить только внешние углы примерно на 4% радиуса, без теней, 3D, bevel и текста. Результат визуально проверен; дальнейшая генерация изображений для сборки не нужна.

`scripts/extension-icons.ps1` детерминированно экспортирует мастер через System.Drawing: Windows ICO с PNG frames 16/24/32/48/64/128/256, PNG для app header и расширения 16/32/48/128. Store icon128 содержит artwork96 с прозрачными полями16; promo440×280 и optional marquee1400×560 используют тот же мастер. Размеры/контейнеры экспортируются без новой генеративной правки.

EXE/Wails/tray используют `build/windows/icon.ico`; существующий шаблон NSIS ссылается на него для installer/uninstaller и EXE для Start Menu. Фактическая установка shortcuts будет проверена после ручного CWS gate вместе с installer. Технические имена/IDs/пути сохранены.
