# Иконка Mangar Downloader

`source-icon.png` — неизменённая project copy предоставленного `user-provided icon`, SHA-256 `45376f12307525da0b463092ad1ec027e38f4e42a6db1988f2ebdfcb3afb7b2c`.

`../appicon.png` — проверенный мастер с слегка скруглёнными внешними углами и прозрачностью снаружи. Редактирование выполнено встроенным imagegen по project copy: сохранить композицию M + стрелка, цвета и минималистичный стиль; изменить только внешние углы примерно на 4% радиуса, без теней, 3D, bevel и текста. Результат визуально проверен; дальнейшая генерация изображений для сборки не нужна.

`scripts/extension-icons.ps1` детерминированно экспортирует мастер через System.Drawing: Windows ICO с PNG frames 16/24/32/48/64/128/256, PNG для app header и расширения 16/32/48/128. Browser-specific variant использует границы непрозрачного фона мастера (alpha ≥ 128), обрезает по 2,5% пустого фона с каждой стороны и задаёт скругление радиусом 12% стороны. Только M + стрелка вместе с исходными edge pixels уменьшаются равномерно до 91,3% предыдущего размера; освобождённый фон восстанавливается из соседних пикселей той же строки, границы/углы tile не меняются. Bbox знака 84×78 px в PNG128, фон заполняет canvas без дополнительного padding/рамки. Все четыре PNG пересобираются из промежуточного artwork1024, не из маленьких иконок. Store icon128 совпадает с extension icon128 при отдельной подготовке store assets; существующие store/release assets текущим pass не обновляются. Promo440×280 и optional marquee1400×560 используют исходный desktop-мастер. Размеры/контейнеры экспортируются без новой генеративной правки.

Для подготовки только browser assets: `pwsh -NoProfile -File scripts/extension-icons.ps1 -ExtensionsOnly`. Этот режим обновляет только `browser-extension/icons/{16,32,48,128}.png`, не меняет desktop ICO/app header и не записывает ничего в `dist/release`. Он не повышает extension version и не публикует пакет в Chrome Web Store.

EXE/Wails/tray используют `build/windows/icon.ico`; существующий шаблон NSIS ссылается на него для installer/uninstaller и EXE для Start Menu. Фактическая установка shortcuts будет проверена после ручного CWS gate вместе с installer. Технические имена/IDs/пути сохранены.
